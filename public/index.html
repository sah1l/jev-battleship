      How Jev decides
      • Each turn it gets the whole chart, the cell states, the ship lengths and the rules. Your ship positions are never sent.
      • Every untested square is offered as an option, described by what has been observed around it. It returns a probability for each one and the highest is fired at.
      • No local code picks, scores or filters targets. The only check is that the square has not been fired at.
      • The percentages are how strongly Jev prefers a square, not the odds that a ship sits there.

      Jev is a System One model from TypeSafe AI. Source and benchmarks.
